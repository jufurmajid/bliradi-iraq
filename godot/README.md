# بريالدو العراقي — Godot Edition 🎱

مشروع **Godot 4.5.2** أصلي، وليس تغليفاً للعبة الويب. تم بناؤه بــ GDScript وواجهة ثنائية الأبعاد مخصصة لشاشات أندرويد بالعرض.

## الموجود بالنسخة الأولية

- قائمة رئيسية أنيقة بمستويات الكمبيوتر: سهل / متوسط / محترف.
- طاولة بليارد مرسومة داخل Godot بنظام 60 تحديث فيزيائي بالثانية؛ 16 كرة وجيوب الستة وتصادم واقعي مبسط.
- تصويب باللمس على الطاولة، ثم **سحب مسطرة القوة للأسفل وإفلاتها للتسديد**.
- كمبيوتر يقدر يستهدف الكرات والجيوب ويمرر الدور ويرجع يلعب مرات متتالية.
- قواعد 1 و15: فقط الجيبان الوسطيان، والكرة الثانية في الوسطي المقابل؛ مخالفة القاعدة ترجع المرقمة وراء خط البداية وتبقى البيضاء بمكانها.
- دخول البيضاء بجيب = يرجع اللاعب البيضاء إلى منطقة ما وراء خط البداية؛ فاول أول ملامسة لكرة الخصم أو إدخال كرته = لا تتحرك البيضاء.
- الكرة 8: اختيار جيب التوب قبل التسديد؛ الجيب غير المحدد أو اللعب المبكر خسارة.
- أصناف الكرات 1–7 / 9–15 مؤقتة لتقسيم اللعب، إلى أن تتأكد قواعد إضافية من صاحب المشروع.

## تشغيل المشروع

افتح `project.godot` باستخدام محرر Godot 4.5.2 أو Godot 4.5+ ثم اضغط Play.

### تصدير APK من موبايل أندرويد

يمكنك فتح مجلد المشروع في **Godot Editor for Android** ثم اختيار **Project → Export → Android** أو تصديره مسبقاً بواسطة أدوات التصدير في محرر الهاتف. إصدار المحرر وقوالب التصدير ينبغي أن يكونا متوافقين.

### APK تلقائي عبر GitHub Actions

الملف `.github/workflows/build-godot-apk.yml` (على جذر المستودع) يبني نسخة APK تجريبية بعد رفع التحديثات داخل `godot/` إلى GitHub. لتحميله، افتح تبويب **Actions → Build Briyaldo Godot APK** ثم افتح آخر تشغيل ناجح وحمّل **Briyaldo-Iraqi-Godot-Android-APK** من Artifacts. تحتاج إلى تسجيل دخول GitHub.

> الملف `export_presets.cfg` هو إعداد للنسخة التجريبية الموقعة بمفتاح مؤقت أثناء البناء. **لا** يُستخدم مفتاح البناء التجريبي للتحديثات المنشورة أو التوزيع عبر متجر Google Play، إذ يتطلب ذلك مفتاح إصدار ثابتاً محمياً.

## بنية الملفات

- `scenes/main.tscn` المشهد الرئيسي.
- `scripts/main.gd` الواجهة، شاشة البداية، نقاط اللاعبين، والقائمة.
- `scripts/table.gd` المحرك الفيزيائي والقوانين وAI والرسم.
- `scripts/power_gauge.gd` تحكم سحب وإفلات المسطرة.
- `export_presets.cfg` إعداد التصدير التجريبي لأندرويد.

## حدود هذه النسخة

النسخة **نواة أصلية قابلة للتطوير** وليست بعد لعبة ثلاثية الأبعاد أو نسخة نهائية متقنة الفيزياء. لم نختبرها على هاتف فعلي ضمن بيئة البناء، ويجب تجربة اصطدام الكرات والفاولات والأداء قبل وصفها كنسخة جاهزة للنشر العام. طور لاعب ضد لاعب أونلاين غير موجود حالياً.
