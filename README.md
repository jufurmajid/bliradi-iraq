# 🎱 بريالدو العراقي — Iraqi Billiards

لعبة بليارد عراقية تعمل من متصفح الأندرويد أو الكمبيوتر، بطور **لاعب ضد الكمبيوتر** (سهل / متوسط / محترف). الإصدار 0.2 تجريبي ومفتوح لتعديل القوانين.

## التشغيل على Termux

```bash
pkg install git python -y
git clone https://github.com/jufurmajid/bliradi-iraq.git
cd bliradi-iraq
python -m http.server 8080
```

افتح `http://127.0.0.1:8080` على نفس الجهاز. بعد التحديثات نفّذ `git pull` داخل المجلد ثم أعد تحديث المتصفح (إذا رأيت التصميم القديم امسح كاش الصفحة). بدون الحاجة إلى Node.js أو خادم خارجي، ولا يحتاج الإنترنت أثناء اللعب؛ خط Google الاختياري يستبدل بخط الجهاز عند انقطاع الإنترنت.

## التحكم

- المس واسحب على الطاولة لتوجيه العصا، واضبط شريط القوة واضغط «اضرب الكرة».
- إذا سقطت البيضاء بجيب، اسحبها لوضعها **داخل المنطقة الواقعة خلف الخط على يسار الطاولة فقط**، ثم صوب.
- عند الوصول إلى السوداء، اختر الجيب المقصود (التوب) من الأزرار فوق شريط القوة، ثم اضرب.
- زر ملء الشاشة يفيد خصوصاً عند تدوير الموبايل إلى الوضع الأفقي.

## القوانين المطبقة

- الكرتان **1 و15** لا تدخلان إلا الجيبين الوسطيين. إذا دخلت إحداهما بجيب مخالف تحتسب فاول، وتُعاد الكرة المرقمة خلف خط البداية وتبقى البيضاء بمكانها.
- بعد دخول إحداهما في جيب وسطي، يجب أن تدخل الأخرى في **الجيب الوسطي المقابل**.
- دخول البيضاء بأي جيب فاول: تُعاد لوضعها خلف خط البداية، ولا يمكن نقلها إلى يمين الخط.
- لمس كرة الخصم قبل كرتك أو إدخال كرة الخصم فاول: **البيضاء لا تتحرك من موضع توقفها**.
- الكرة السوداء **8** بنظام التوب: الدخول في جيب مختلف خسارة؛ كذلك إدخال السوداء قبل أوانها.
- **مؤقت حتى نتأكد من بقية قوانين اللعب:** المجموعة 1–7 مقابل 9–15، وتُحدد المجموعة من أول كرة قانونية، ويستمر دور اللاعب عند إدخال كرة من مجموعته دون فاول.

## بنية المشروع

- `index.html`: واجهة القائمة والمباراة.
- `style.css`: التصميم المتجاوب للموبايل والكمبيوتر.
- `game.js`: رسم الطاولة وفيزياء الكرات وقواعد الفاولات والذكاء الاصطناعي.
