# 🎱 بريالدو العراقي — نسخة اللعب ضد الكمبيوتر v0.5

لعبة بليارد عراقية تجريبية للموبايل والمتصفح، مبنية بـ HTML + CSS + JavaScript، تعمل بدون خدمات خارجية.

## التشغيل في Termux

```bash
pkg install git python -y
git clone https://github.com/jufurmajid/bliradi-iraq.git
cd bliradi-iraq
python -m http.server 8080
```

ثم افتح `http://127.0.0.1:8080` في المتصفح. إذا كانت النسخة قديمة فاستعمل `git pull origin main` وحدّث الصفحة تحديثاً كاملاً.

## الواجهة والتحكم

- شاشة بداية لاختيار مستوى الكمبيوتر: سهل، متوسط، محترف.
- عند بدء المباراة يُطلب ملء الشاشة والوضع الأفقي تلقائياً عندما يسمح المتصفح. إذا لم يسمح، دوّر الهاتف يدوياً.
- المس أو اسحب فوق الطاولة لتحديد اتجاه العصا، غيّر القوة من الشريط الجانبي، واضغط **اضرب الكرة**.
- يظهر لكل لاعب صف الكرات بأرقامها (1–7 أو 9–15)، وتبهت الكرات التي دخلت.
- عند الاقتراب من السوداء 8 تُعرض أزرار اختيار الجيب (التوب).
- تصميم أزرق محسّن، رسم كرات وظلال وملمس من Canvas مع عرض عالي الدقة بحسب كثافة الشاشة.

## القوانين المطبقة حالياً

- الكرة 1 والكرة 15 تدخلان فقط الجيبين الوسطين. إذا دخلت إحداهما بجيب آخر فهي فاول وتُعاد الكرة **المرقمة** وراء خط البداية؛ الكرة البيضاء تبقى حيث توقفت.
- إذا دخلت إحداهما في جيب وسطي، يجب إدخال الأخرى في الجيب الوسطي المقابل.
- فاول دخول البيضاء في أحد الجيوب: تُخرَج البيضاء ويمكن وضعها فقط خلف خط البداية العمودي.
- فاول لمس كرة الخصم أولاً أو إدخال كرة من مجموعته: تبقى البيضاء في مكان توقفها.
- يجب تحديد جيب السوداء (التوب). دخولها في جيب مختلف خسارة.
- توزيع المجموعات الصلبة/المخططة (1–7 و9–15) واستمرار الدور بعد إدخال كرة قانونية افتراضان مؤقتان، ما زالا بحاجة تأكيد من صاحب المشروع.

## حدود النسخة

الطور المتاح الآن لاعب ضد الكمبيوتر على نفس الجهاز. هذه نسخة ثنائية الأبعاد على Canvas، وليست نسخة من لعبة تجارية ولا محاكاة فيزياء 3D متقدمة. يحتاج الذكاء الاصطناعي والفيزياء المزيد من الاختبارات. اللعب ضد الأصدقاء أونلاين سيضاف لاحقاً.

صناعة **جعفر ماجد**.

## التسديد الجديد (v0.5)

1. المس الطاولة لتحديد اتجاه العصا.
2. اسحب مسطرة القوة الجانبية **للأسفل** لاختيار القوة.
3. **اترك إصبعك** لتسديد الكرة تلقائياً، بدون زر تسديد.
4. إذا سحبت مسافة قصيرة جداً ثم تركت، لا تنفذ الضربة.

تحسين الأداء: خلفية الطاولة تُحفظ بالرسم خارج الشاشة، وتُحدَّث الكرات أثناء الحركة عند نحو 40 إطار في الثانية مع استمرار حساب الفيزياء عند 60 خطوة في الثانية. حجم Canvas يتكيّف مع الدقة الفعلية للعرض لتجنب اللاگ على الهواتف.
