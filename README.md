# 🎱 بريالدو العراقي

لعبة بليارد عراقية تجريبية تعمل بالكامل داخل المتصفح، مصممة للموبايل مع طور **لاعب ضد الكمبيوتر**.

## التشغيل

افتح `index.html` في أي متصفح حديث، أو شغّل الموقع عن طريق GitHub Pages. ما يحتاج سيرفر، تسجيل دخول، أو مكتبات خارجية. يفضل تدوير الهاتف بالعرض.

## خصائص النسخة 0.1

- تصويب باللمس، شريط قوة، فيزياء حركة واصطدام وجيوب.
- كمبيوتر بثلاثة مستويات صعوبة مع محاولات اختيار الكرة والجيب.
- الكرة 1 والكرة 15 للجيبين الوسطيين فقط؛ دخولها بأي جيب غير مسموح يرجّع الكرة المرقمة وراء خط البداية والبيضاء تبقى بمكانها.
- دخول إحداهما في جيب وسطي يلزم الثانية بالجيب الوسطي المقابل.
- دخول البيضاء في الجيب يسمح بوضعها فقط وراء الخط العمودي على يسار الطاولة.
- لمس كرة الخصم قبل كرتك أو إدخال كرة الخصم فاول، دون تحريك البيضاء من مكان توقفها.
- تختار الجيب مسبقاً (التوب) للسوداء 8. إدخالها بجيب آخر خسارة.

## افتراضات مؤقتة بحاجة تأكيد

هذه ليست قوانين نهائية أقرّها صاحب اللعبة: تقسيم الكرات إلى 1–7 و9–15، إسناد المجموعة من أول كرة قانونية، استمرار الدور عند إدخال كرة، منع السوداء قبل إكمال المجموعة، والفاول عند عدم لمس أي كرة. تُراجع هذه الافتراضات بعد تجربة النسخة الأولى.

## تطوير لاحق

- تدقيق قواعد اللعبة بالتجربة وتوضيح الحالات النادرة.
- تحسين المؤثرات، الفيزياء، ذكاء الكمبيوتر، والتحكم باللمس.
- إضافة طور لاعب ضد لاعب أونلاين بالغرف والدعوات بخادم مزامنة.
